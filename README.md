# Sistema de Gestión del Mundial de Fútbol

> Trabajo práctico correspondiente a la materia **Bases de Datos Aplicadas**  
> **Ingeniería en Informática** — Universidad Nacional de La Matanza (UNLaM)

## Descripción

Este proyecto implementa una base de datos relacional orientada a la gestión integral del campeonato mundial de la FIFA. El sistema permite administrar los partidos del torneo, las sedes, las selecciones participantes con sus planteles y cuerpos técnicos, el seguimiento de eventos en cancha (alineaciones, cambios, goles y tarjetas), el control disciplinario, arbitraje y la gestión de pautas publicitarias durante la competencia.
